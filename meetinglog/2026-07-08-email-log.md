**Kiosk Mode Issue & Resolution**

- **Problem:** Fully Kiosk Browser (Plus version) was unstable, page freezes, exits to Android home screen, 3D model fails to render; no issues in Chrome or mobile browsers
- **Root cause identified:** launching the VR walkthrough creates a second WebGL context, eventually running the GPU out of memory; graphics driver doesn't fully recover even after leaving VR
- **Attempted fixes:** FreeKiosk (Valerio's suggestion), PWA conversion, lowered rendering quality, on-demand rendering, limited pixel ratio, FPS watchdog with static-image fallback — all helped slightly but were not stable enough
- **Final solution (stable):**
  - Tablet opens a lite URL: `https://0022-fyp.vercel.app/?lite=1`
  - Interactive 3D model retained at lower quality for reliable performance
  - VR button replaced with a QR code so visitors can open the full VR experience on their own phones
  - Running via FreeKiosk; stable in testing so far
- Valerio confirmed: solution makes sense; removing the VR button is fine, keeps the experience streamlined, and the QR code covers the full VR option

**Suggestions from Valerio**

- Recommended FreeKiosk (open-source): https://freekiosk.app/download/
- Suggested converting the site into a Progressive Web App (PWA) using the Vite PWA plugin for easier kiosk management
